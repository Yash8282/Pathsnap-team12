# HMM decoding results (model probabilities from lightgbm / mlp)

Produced by `python scripts/05_tune_hmm.py --probs <model>`. Decoder parameters tuned on train out-of-fold
probabilities of every 3rd train trip (26 trips), then evaluated once on student_test.
Probabilities were regenerated by re-running `scripts/models/train_<model>.py` with seed 42; the metrics matched the
committed `results/experiments/<model>.json` to four decimals.

Known caveat: several tuned parameters sit on the edge of the search grid (see `best_params.json` vs `GRID` in
`scripts/05_tune_hmm.py`), so a wider grid could change the result, especially for mlp.
